# Security

This program does not take an API key, does not open a network connection, and does not store an account. Inputs you type stay in the process, or in the browser tab if you use the static page.

Do not paste a key, a signature, or an account identifier into an issue anyway. A bug report needs the inputs and the output, not your identity at a venue.

If you find a vulnerability, open a private security advisory on this repository. Do not file a public issue that includes a working exploit against a dependency, and do not include credentials of any kind.

The liquidation and IL figures are a model. A wrong model can lead a person to take a larger position than they meant. Treat a formula bug as a real bug. Include the input, the output, and the number you believe the formula should produce.
