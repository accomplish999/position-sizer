- [Examples](EXAMPLES.md). The inputs in `examples/`, and the text the CLI prints.
- [Agents](AGENTS.md). How to call this from a script without guessing.
- [FAQ](FAQ.md).
- [Glossary](GLOSSARY.md).

Start with the example that matches the question you actually have. Then read the formula for that output, not the whole pile.
