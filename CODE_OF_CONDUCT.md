# Code of conduct

Be specific. Be decent. Disagree about the code, not about the person who wrote it.

Do not harass, threaten, or post someone else's private information. Do not paste API keys, signatures, or account ids. A vulnerability goes through a private advisory, as `SECURITY.md` says.

This repository is a calculator. Do not ask the maintainers to promise a return, and do not present a result as if the next trade will match it. Past results do not predict future results.

Maintainers can edit or close an issue or a pull request that breaks these rules. They can also block a repeat offender from the repository.
